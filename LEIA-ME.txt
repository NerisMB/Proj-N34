N34 — versão para GitHub Pages
==============================

ARQUIVOS (envie TODOS para o repositório, na raiz)
  index.html            o site
  404.html              faz funcionar /favorites, /explore, /following, /top, /groups e /gallery
  .nojekyll             impede o GitHub de ignorar arquivos
  sw.js                 deixa o app instalável e abrindo mesmo sem internet
  manifest.webmanifest  dados do app instalável (ícone, nome, atalhos)
  icons/                ícones do app

PUBLICAR
1. Crie um repositório no GitHub e envie todos os arquivos acima (Add file > Upload files).
2. Settings > Pages > "Deploy from a branch" > branch main, pasta / (root) > Save.
3. Em 1 ou 2 minutos o site abre em https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/
   (se o repositório se chamar SEU-USUARIO.github.io, abre direto em https://SEU-USUARIO.github.io/).
Para atualizar depois: envie o index.html novo por cima (e o sw.js, se ele mudar).

CONFIGURAR (⚙ no site)
- Cole o User ID e a API key do Rule34 (rule34.xxx > Minha conta > Opções) e toque em Salvar.
  Ficam salvos só no navegador.

INSTALAR NO CELULAR
- Botão "Instalar o N34 no celular" na página inicial.
  Android/Chrome: instala com um toque. iPhone: Safari > Compartilhar > Adicionar à Tela de Início.

SINCRONIZAR ENTRE APARELHOS
Entre no site em cada aparelho, abra ⚙ e use o MESMO User ID e a MESMA API key do Rule34. A sincronização começa sozinha.
Seus dados vão cifrados no aparelho (com User ID + API key) para o textdb.online; o serviço só vê texto embaralhado.
A bolinha em ⚙ > Sincronização mostra o estado: verde = em dia, amarela = sincronizando, vermelha = erro.

IMAGENS E VÍDEOS
- O visualizador abre a imagem na versão reduzida e troca sozinho pela ORIGINAL.
  Para poupar dados: ⚙ > desmarque "Imagens em qualidade original no visualizador".
- A duração dos vídeos é lida no máximo 2 por vez e espera quando você abre um vídeo.

O QUE NÃO EXISTE NO GITHUB PAGES (não há servidor)
- Copiar imagens para Galeria/Grupos "pelo servidor" e a busca automática de ícones. O resto funciona normalmente.
- Para levar dados sem sincronizar, use Exportar/Importar backup no ⚙.


--- SINCRONIZAÇÃO (GitHub Pages) ---
A sincronização usa o seu User ID + API key do Rule 34: os dados (favoritos, grupos, galeria, seguindo, blacklist) são cifrados no aparelho
e guardados no serviço gratuito textdb.online. Em outro aparelho, entre com o mesmo User ID e API key. Quem não souber os dois não consegue abrir os dados.
O token do GitHub (Gist) continua existindo como opção, mas não é mais necessário.


--- DICA SOBRE A SINCRONIZAÇÃO ---
Em Configurações, o botão "Testar" (ao lado de "Sincronizar agora") mostra em qual etapa a sincronização falha: envio ou leitura no textdb.online.


NOVIDADE: ao tocar em um favorito que postou algo novo, ele é marcado como lido automaticamente (some o destaque da lista e da página inicial e o contador diminui). "Marcar tudo como visto" continua existindo.

CORREÇÃO DA SINCRONIZAÇÃO
- Fora do github.io (por exemplo, no Netlify), o site tentava usar uma função /api/sync que não existe nesta versão e mostrava
  "a função de sincronização não está publicada neste site (404)". Agora ele detecta isso sozinho e usa o textdb.online.
- Em ⚙ > Sincronização, depois de "ok" aparece "via textdb.online". O botão "Testar" mostra qual caminho está sendo usado.
- Se o textdb.online confirmar o envio mas demorar a mostrar o dado (cache), a sincronização não dá mais erro à toa.

MAIS NOVIDADES
- ⚙ > Sincronização > "Desfazer última": aparece depois que a sincronização trouxe mudanças do outro aparelho e deixa voltar ao que este aparelho tinha antes
  (a versão restaurada também é enviada aos outros aparelhos). Não aparece na primeira sincronização de um aparelho vazio.
- Página inicial: as buscas salvas (★) aparecem logo acima das pesquisas recentes, com um toque para repetir.

SINCRONIZAÇÃO (atualização)
- Erro "Failed to fetch": acontecia quando o servidor do site não respondia (ou o site era aberto como arquivo). Agora o site passa sozinho
  para o textdb.online. Se a rede bloquear tudo, a mensagem explica (internet, VPN ou bloqueador de anúncios).
- Bolinha no cartão Sincronização (verde / amarela piscando / vermelha), com a hora da última sincronização e o resumo na linha de baixo.
- A sincronização roda sozinha a cada 2 minutos com o site aberto e quando a internet volta.

MEUS LINKS (menu ☰)
- No menu dos três traços (☰), toque em "Links": abre a folha "Meus links" com "＋ Adicionar", "Copiar todos" e "Editar" (↑ subir, ✎ renomear, ✕ remover).
- "Copiar todos" copia uma linha por link neste formato:
  * || https://linkteste.com || - ** Título do Link **
- Só aceita endereços http/https. Os links entram na sincronização e no backup (iguais no PC e no celular).

  * O servidor do site e o textdb.online têm tempo limite; se travar, aparece o erro e dá para tentar de novo (Sincronizar agora).
