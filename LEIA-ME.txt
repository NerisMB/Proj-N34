COMO PUBLICAR O N34 COM SINCRONIZAÇÃO (Netlify)

A sincronização entre aparelhos precisa da função netlify/functions/sync.mjs.
Se ela não for publicada, o painel mostra "erro (servidor 404)".
Arrastar a pasta no Netlify Drop NÃO publica essa função. Use um dos caminhos abaixo.

CAMINHO A - GitHub (recomendado)
1. Crie um repositório no GitHub e envie TODO o conteúdo desta pasta
   (index.html, sw.js, _redirects, _headers, manifest.webmanifest, icons/,
    netlify/functions/sync.mjs, package.json, netlify.toml).
2. No Netlify: Add new site > Import an existing project > escolha o repositório.
   Deixe o "Build command" vazio e o "Publish directory" como "." (ponto).
3. Depois do deploy, no painel do site, abra a aba "Functions": deve aparecer "sync".

CAMINHO B - Netlify CLI (no computador, com Node instalado)
1. Dentro da pasta: npm install
2. npm install -g netlify-cli
3. netlify login
4. netlify link          (escolha o site n34)
5. netlify deploy --prod --dir=. --functions=netlify/functions

COMO TESTAR SE A FUNÇÃO ESTÁ NO AR
Abra no navegador: https://SEU-SITE.netlify.app/.netlify/functions/sync?id=teste
- Aparece "id inválido"  -> a função está publicada (tudo certo).
- Aparece "Page not found" / 404 -> a função NÃO foi publicada; refaça o caminho A ou B.

Depois, abra o site nos dois aparelhos e use ⚙ > Sincronizar agora.


SEGURANÇA E PRIVACIDADE (versão atual)
- Política de segurança (_headers): o site só se conecta a api.rule34.xxx, danbooru.donmai.us (foto do artista),
  unavatar.io e ao próprio endereço. O campo "Proxy CORS" do ⚙ deixa de funcionar a menos que você adicione o
  endereço dele em connect-src dentro de _headers.
- Função sync.mjs: só aceita pedidos feitos pelo próprio site, limita pedidos por IP e exige a "prova" da chave
  para gravar. IMPORTANTE: publique o index.html NOVO junto com o sync.mjs NOVO. Versões antigas do site não enviam
  a prova e a sincronização delas passa a dar erro 401.
- No ⚙: Exportar/Importar backup, medidor de armazenamento, Modo economia e "Não lembrar a API key".


--- ÍCONES DOS PERSONAGENS SEGUIDOS (opcional) ---
O Google encerrou a API oficial de busca de imagens, então a busca automática usa a Brave Search API.
1) Crie uma chave em https://brave.com/search/api/ (confira o plano gratuito e os limites).
2) No Netlify -> Environment variables, crie: BRAVE_API_KEY = (sua chave) e faça o deploy de novo.
Sem a chave, o ícone vem da miniatura de um post do personagem, e você pode trocar na mão (botão do Google, colar endereço ou enviar foto).
